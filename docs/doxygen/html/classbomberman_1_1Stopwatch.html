Detailed Description

Singleton die het tijdsverschil (deltaTime) tussen twee update-ticks bijhoudt. Wordt gebruikt door zowel de logic (beweging, bom-timers) als de representatie (animatie-timing), zonder ooit busy waiting te gebruiken.
