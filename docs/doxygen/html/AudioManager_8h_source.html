8// ============================================================
9// AudioManager.hpp
10// Speelt geluidseffecten en achtergrondmuziek af als reactie op Events uit
11// de logic-library - exact het Observer-patroon dat Views al gebruiken om
12// te tekenen, nu voor geluid. AudioManager wordt op twee plaatsen
13// aangesloten:
14// 1) op World zelf (world_->attach), voor events die World rechtstreeks
15// notify't: BombPlaced, PlayerDied, PlayerWon, EnemyKilled.
16// 2) op elke entiteit via ConcreteFactory::create*() (model->attach),
17// voor events die de entiteit zelf notify't: BombExploded,
18// BlockDestroyed, PowerUpCollected, Damaged, Died.
19// Die twee groepen events overlappen niet, dus er is geen risico op een
20// geluid dat dubbel afspeelt voor dezelfde gebeurtenis.
21//
22// Ontbrekende geluidsbestanden zijn geen fatale fout: net als het lettertype
23// in Game.cpp wordt een missend bestand gewoon overgeslagen (een waarschuwing
24// op stderr) zodat het spel ook zonder audio-assets blijft draaien.
25// ============================================================
